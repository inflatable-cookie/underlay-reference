# Underlay Reference required-secret authority (contracts 024 and 031).
#
# Startup-critical keys only: without them the API cannot boot, or can only
# boot in the bounded non-deployed environment set. Every key here must also
# appear in config/env-manifest.txt. Values are never recorded here — presence
# is a runtime and operator concern, checked by the operator's own tooling and
# never by CI.
#
# Conditional adapter and backend credentials are deliberately absent. Redis,
# SMTP, SES/AWS, Google OAuth, and object-store keys become mandatory only when
# the matching backend is selected, so listing them here would claim unused
# providers are required. Their conditions are recorded in
# config/env-manifest.txt.
#
# This file, root `effigy.toml` `[secrets.keys]`, and the README secrets table
# are three views of one policy and must agree. Effigy's `required` flag is a
# single boolean and cannot express a condition, so where a key here is
# conditional, the block below states the condition and names why the Effigy
# declaration is not `required = true`.

# Required in every environment. No fallback exists: the API refuses to start
# without these, and the Effigy declarations mark both `required = true`.
AUTH_JWT_PRIVATE_KEY
AUTH_JWT_PUBLIC_KEY

# Required as an injected secret in deployed environments (dev, staging,
# production, and any unrecognised name).
#
# Local exception: local and effigy resolve the database URL from the
# committed non-secret `config/effigy.toml` overlay, so the dev loop needs no
# vault value. That is why the Effigy declaration is `required = false` — a
# hard requirement would block a loop the committed overlay already serves.
# The API still cannot start without a URL from one source or the other.
DATABASE_URL

# Required in deployed environments (dev, staging, production, and any
# unrecognised name). In local, effigy, and test it may be absent: startup
# continues with an explicit warning and TOTP secrets are stored in plaintext.
# The Effigy declaration is `required = false` for that reason.
ENCRYPTION_KEY
