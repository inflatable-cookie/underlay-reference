# Release

This repository is a bootstrap template, not a published package. There is no
versioned tag, registry publication, or release train. People copy the repo
and rename `acme`.

Application dependencies pin released Underlay and Poodle tags. Changing those
pins is ordinary product work, not a release of this repository.

## What would change that

A release procedure would be needed if this repo itself were published as a
versioned artifact. Until then, the steps below do not apply.
