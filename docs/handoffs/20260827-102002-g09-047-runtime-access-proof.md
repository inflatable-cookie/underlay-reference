- **Why the roadmap is ready:** the shared contracts are active; Underlay
  `v0.9.5` exists with green exact-source/release CI and tagged-consumer smoke;
  target main is exact and clean; and the operator explicitly settled every
  security gate.
- **Settled environment classes:** `local`, `effigy`, and `test` are the only
  bounded non-deployed environments. `dev`, `staging`, and `production` are
  deployed. Unknown names retain Underlay's fail-closed production behavior.
- **Settled startup authority:** `DATABASE_URL`,
  `AUTH_JWT_PRIVATE_KEY`, and `AUTH_JWT_PUBLIC_KEY` are required for the API.
  `ENCRYPTION_KEY` is additionally mandatory outside local/effigy/test and may
  be absent with an explicit warning only inside that set. Redis, SMTP,
  SES/AWS, and storage credentials are conditional on the selected
  backend/adapter. Public keys may be non-secret, but remain startup-critical
  authority.
- **Settled CSRF policy:** CSRF may be disabled only in
  local/effigy/test. Dev, staging, production, and unknown names must reject an
  attempted disablement. Cookie-backed authenticated mutations, including
  passkey registration, stay protected. Bearer/bootstrap-only endpoints retain
  the route-family contract's bounded exemptions.
- **Settled failure policy:** malformed layered config and
  `COOKIE_SECURE=false` are fatal outside local/effigy/test. The bounded
  non-deployed set may warn where startup remains useful.
- **Current env drift:** no root `config/env-manifest.txt` or
  `config/required-secrets.txt` exists. `apps/acme-api/.env.example` is tracked;
  root README simultaneously rejects `.env` files and tells operators to use
  one. Active architecture docs still point to that file. Inventory every live
  runtime reader; classify behavior knobs into typed config instead of blindly
  memorializing legacy env drift.
- **Current config drift:** `AppBehaviorConfig::load()` warns and falls back to
  defaults after any config-stack parse failure. `main.rs` only warns when
  `COOKIE_SECURE=false` outside development. Both need the settled
  environment-aware fatal boundary and direct tests.
- **Current CSRF drift:** `csrf_protection_middleware` reads
  `CSRF_PROTECTION` per request and bypasses all mutation checks whenever it is
  false. Its exemption list includes passkey registration start/finish even
  though those routes are authenticated cookie-backed mutations. Resolve policy
  once at bootstrap and test the environment boundary plus the passkey slice.
- **Current proxy drift:** bootstrap installs Underlay's peer-aware
  `RequestContext` extension and `ConnectInfo`, but auth handlers still call the
  app-local header-based `acme_infra::extract_client_ip`. Route policy inputs
  for auth, lockout/rate-limit, audit, and fingerprints must consume one
  centralized peer-aware request context. Do not trust forwarding headers
  merely because a header exists.
- **Current route topology:** `routes/mod.rs` registers runtime health/OpenAPI,
  shared auth/account, product task/project-description, and admin routes in
  one builder; health currently lives under `shared`. Introduce explicit
  shallow runtime/shared/front/admin builders while preserving the current
  paths and omitting empty families.
- **Current version posture:** path versioning is baseline. Runtime endpoints
  never require the business API-version header. If Underlay Reference retains
  its declared header, apply it consistently to business families only and
  document that posture; do not invent a URL or header cutover.
- **Current dependency surface:** four JavaScript workspace manifests and the
