# Logs

Logs capture meaningful execution batches for the reference implementation.

## Rules

- Use month folders: `YYYY-MM/`.
- Use timestamped filenames: `DD-HHMMSS-slug.md`.
- Tie logs back to the roadmap ID when the work belongs to a roadmap.
- Write logs per meaningful update batch, not for every small task.
